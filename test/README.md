# 集成测试 / 端到端测试

单元测试与源码放在同一个包内（`*_test.go`），直接运行：

```bash
go test ./...
```

本目录用于放需要真实依赖的测试，后续建议使用 `testcontainers-go` 启动临时的
MySQL 与 Redis，避免依赖本机开发数据：

- 账号：游客登录、令牌刷新轮换、注销
- 玩家：资料读取、昵称修改
- 剧情：进度覆盖写入、跨章节读取
- 数据库：迁移在空库上可重复执行

约定：

- 使用 build tag（如 `//go:build integration`），默认 `go test ./...` 不执行；
- 测试自行创建并清理数据，不读写开发库；
- 每个测试使用独立的 device_id / user_id，保证可并行。
